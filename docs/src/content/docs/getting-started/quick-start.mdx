A CFONB 120 file is a list of 120 characters lines. This one holds three statements of two accounts:

<SampleFile name="statements.txt" />

Give its contents to a `Cfonb120Reader`: `parse()` returns one `Statement` per opening (`01`) and closing (`07`)
balance pair, with the operations (`04`) between them.

<Example name="quick-start" />

Every example of this documentation parses the files of
[`docs/examples/`](https://github.com/silarhi/cfonb-parser/tree/6.x/docs/examples), and the outputs shown are what the
library really prints.

## Both formats

`CfonbReader` reads both formats, through a `Cfonb120Reader` and a `Cfonb240Reader`:

<Example name="cfonb-reader" />

| Method                                                       | Same as                                  |
| ------------------------------------------------------------ | ---------------------------------------- |
| `parseCfonb120(string $content, bool $strict = true): array` | `Cfonb120Reader::parse()`, `Statement[]` |
| `parseCfonb240(string $content, bool $strict = true): array` | `Cfonb240Reader::parse()`, `Transfer[]`  |
