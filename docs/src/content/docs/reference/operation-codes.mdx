`Operation::getCode()` returns the CFONB operation code of a CFONB 120 operation (positions 33–34). The static array
`Silarhi\Cfonb\CfonbCodes::$codes` describes each code:

| Key           | Value                                              |
| ------------- | -------------------------------------------------- |
| `label`       | The French label of the CFONB                      |
| `way`         | `D` debit, `C` credit, `D/C` or `C/D` either       |
| `swift_code`  | The SWIFT MT940 transaction type                   |
| `swift_label` | Its English label                                  |
| `swift_way`   | The direction on the SWIFT side, the same as `way` |
