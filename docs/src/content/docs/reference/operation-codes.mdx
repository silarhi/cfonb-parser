`Operation::getCode()` returns the CFONB operation code of a CFONB 120 operation (positions 33–34) as a string. Since
6.7, `Operation::getOperationCode()` returns it as a case of the `Silarhi\Cfonb\OperationCode` enum, which describes it:

| Method                   | Returns                                                                                               |
| ------------------------ | ----------------------------------------------------------------------------------------------------- |
| `label(): string`        | The French label of the CFONB                                                                         |
| `direction(): Direction` | `Debit`, `Credit`, `DebitOrCredit` or `CreditOrDebit`; `canDebit()` and `canCredit()` tell them apart |
| `swiftCode(): string`    | The SWIFT MT940 transaction type                                                                      |
| `swiftLabel(): string`   | Its English label                                                                                     |

<Example name="operation-codes" />

A bank can send a code missing from the list: `getOperationCode()` is then `null`, as `OperationCode::tryFrom()` is.
Compare an operation with a case, `$operation->getOperationCode() === OperationCode::SepaDirectDebitsDomiciled`, rather
than with its code.

The static array `CfonbCodes::$codes` holds the same data: it is deprecated since 6.7, and removed in 7.0.
